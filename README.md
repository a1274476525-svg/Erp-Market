# يو ماركت – نظام إدارة السوبرماركت

تطبيق سطح مكتب لإدارة المبيعات والمشتريات والمخزون والفروع والحسابات، مبني باستخدام React وTypeScript وElectron وPrisma وSQLite.

## تحميل نسخة Windows وتجربتها

يتم إنشاء ملف تثبيت Windows تلقائيًا عند تحديث الفرع الرئيسي `main`.

1. افتح تبويب **Actions** في مستودع GitHub.
2. اختر أحدث تشغيل ناجح باسم **Windows installer**.
3. افتح التشغيل ثم قسم **Artifacts**.
4. حمّل `U-Market-Windows-Installer` وفك ضغط الملف.
5. شغّل ملف التثبيت `.exe`.

عند أول تشغيل، أنشئ حساب مدير النظام ورقم دخول من 4 أرقام. لا يوجد رقم دخول افتراضي.

> ملاحظة: ملف التثبيت غير موقّع بشهادة تجارية، لذلك قد يعرض Windows تحذيرًا عن الناشر.

## النسخ الاحتياطي

قاعدة البيانات محلية على جهازك. استخدم صفحة الإعدادات داخل التطبيق لإنشاء نسخة احتياطية قبل تجربة مسح البيانات أو إجراء تغييرات كبيرة. لا تختبر حذف البيانات على قاعدة بيانات العمل الأساسية.

## تشغيل المشروع للمطورين

يتطلب Node.js 20 أو أحدث، ويجب تنفيذ الأوامر من مجلد المشروع الذي يحتوي على `package.json`.

### Windows PowerShell

```powershell
npm ci
$env:DATABASE_URL = "file:./umarket.db"
npm run db:generate
npm run db:push
npm run dev
```

يبقى متغير `DATABASE_URL` مضبوطًا طوال جلسة PowerShell الحالية. إذا أغلقت النافذة وفتحت أخرى، اضبطه مرة ثانية قبل أوامر Prisma.

### macOS / Linux

```bash
npm ci
export DATABASE_URL="file:./umarket.db"
npm run db:generate
npm run db:push
npm run dev
```

> استخدم أوامر `npm run db:generate` و`npm run db:push` الموجودة في المشروع بعد `npm ci`، بدل تشغيل Prisma من تثبيت عابر عبر `npx`. لا تنفّذ `db:push` على قاعدة بيانات العمل قبل أخذ نسخة احتياطية. مسار `file:./umarket.db` يُحل بالنسبة إلى ملف Prisma schema داخل مجلد `prisma`.

بناء مثبت Windows محليًا:

```powershell
npm run dist:win
```

## ملاحظات الإصدار

- رصيد المنتج الإجمالي يُحسب من أرصدة المخازن.
- نقطة البيع تستخدم رصيد المخزن الافتراضي للفرع الرئيسي.
- يتم التحقق من المخزون داخل عمليات البيع والتحويل والهالك والجرد.
- صلاحيات عمليات IPC الحساسة تُراجع داخل عملية Electron.
- أرقام دخول المستخدمين تُخزّن باستخدام scrypt، وتُحدّث أرقام الدخول القديمة إلى التخزين الآمن عند أول استخدام ناجح.
